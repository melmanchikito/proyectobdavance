# Proyecto de Base de Datos Avanzadas

## Descripción

Repositorio académico destinado al desarrollo de actividades y proyecto de la asignatura de Base de Datos Avanzadas.

## Estado actual

Actualmente el repositorio contiene únicamente la documentación inicial. Todavía no se han incorporado scripts SQL, modelos, diagramas o código ejecutable.

## Contenido recomendado

Cuando se agregue la implementación, se recomienda organizarla así:

```text
proyectobdavance/
├── sql/
│   ├── schema.sql
│   ├── data.sql
│   ├── procedures.sql
│   ├── triggers.sql
│   └── views.sql
├── docs/
│   ├── modelo-er.png
│   └── capturas/
└── README.md
```
